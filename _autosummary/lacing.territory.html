lacing.territory#

Territories: the vocabulary a territory_excluded restriction is written in.

A lacing.Restriction of kind lacing.TERRITORY_EXCLUDED records its codes verbatim (ISO 3166-1 alpha-2 country codes, or a region code such as "EU"). Reading one against a use needs the code set, the spellings that name a country by another code, and what a region covers. They live here, beside the kind, so every consumer (foley’s licence gate, an’s credits) reads codes the same way instead of keeping its own copy (reeleehq/an#743).

>>> normalize_territory(" uk "), normalize_territory("EL"), normalize_territory("")
('GB', 'GR', None)
>>> territory_excluded({"EU", "GB"}, "fr"), territory_excluded({"EU"}, "US")
(True, False)

lacing.territory.territory_excluded(excluded, territory, *, regions={'EU': frozenset({'AT', 'AX', 'BE', 'BG', 'CY', 'CZ', 'DE', 'DK', 'EE', 'ES', 'FI', 'FR', 'GF', 'GP', 'GR', 'HR', 'HU', 'IE', 'IT', 'LT', 'LU', 'LV', 'MF', 'MQ', 'MT', 'NL', 'PL', 'PT', 'RE', 'RO', 'SE', 'SI', 'SK', 'YT'})})[source]#

Whether a use in territory falls in excluded (a region covers its members).

It fails closed on both sides. Whenever anything is excluded, an unstated territory (None), a worldwide one, and one that is not a country code all count as excluded. And a recorded code is read through its aliases: one that names no country, no key of regions and not WORLDWIDE (a typo such as "Franc") excludes every use, since nobody can tell what it meant; a recorded "WORLD" excludes every use by definition.

>>> territory_excluded({"KR"}, None), territory_excluded({"UK"}, "gb")
(True, True)
>>> territory_excluded({"KR"}, "Korea"), territory_excluded(set(), None)
(True, False)
>>> territory_excluded({"KR"}, "WORLD"), territory_excluded(set(), "WORLD")
(True, False)
>>> territory_excluded({"Franc"}, "US"), territory_excluded({"WORLD"}, "US")
(True, True)

bool
